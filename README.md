# CBOE Options Analysis — Honours Thesis

Analyst forecast dispersion (IBES) and its relationship to retail options
trading activity (CBOE Open/Close), 2011 – May 2022.

## Repository layout

```
CBOE_Data_2011_2022/    Raw CBOE per-day zip files go here (not included -- see Setup)
data/
  CBOE_DATA_RAW_EXTRACTED/   Auto-generated by extract_zips.py
  cboe_parquet/               Auto-generated by ingest_cboe.py
  ibes_quarterly_report/      Place your IBES export here (not included -- see Setup)
workbooks/
  00_data_pipeline_setup.ipynb   Historical record of the original pipeline run.
                                 Kept for documentation only -- do not run this;
                                 paths reflect an old folder layout. Use the
                                 scripts below instead.
  A1_data_pipeline_setup.ipynb   Live notebook: path setup + verification.
src/
  paths.py           Single source of truth for every path used project-wide
  extract_zips.py     Converts the raw zip archive to flat CSVs
  ingest_cboe.py       Converts CSVs to yearly Parquet files
  verify_setup.py      Confirms the pipeline output is present and correct requirements.txt
```

## Setup

This repo does not include the raw data. CBOE and IBES are both licensed,
commercial datasets, and CBOE's raw zip archive alone is several GB which I discovered when I attempted my first upload.
Both are available via the same supervisor access already in place with Professor Grant and Professor Westerholm or they can be sourced from CBOE Global Markets and Wharton Research Data Services respectively. For this project 

1. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
2. Place the CBOE per-day zip files in `CBOE_Data_2011_2022/`
3. Place the IBES export in `data/ibes_quarterly_report/`

## Running the pipeline

From the repository root, in order:

```
python src/extract_zips.py
python src/ingest_cboe.py
python src/verify_setup.py
```

Each step's output feeds directly into the next; no arguments are required.
`verify_setup.py` is safe to re-run at any time afterward. Important to note this script only reads
existing output and reports on it, it never modifies anything.

## Notes

- `CBOE_Data_2011_2022` is spelled with this exact capitalisation on disk.
  Windows won't care if it doesn't match, but Mac and Linux will. I know that professor Westerholm uses a Mac.
- The CBOE dataset provided runs from 2011-01-03 through 2022-05-16, not
  through 2022 in full. This was confirmed by both the ingestion output and an
